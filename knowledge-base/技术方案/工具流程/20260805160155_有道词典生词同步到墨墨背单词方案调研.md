### 2.5 关键接口详解

#### 云词本 —— notepads

云词本 content 字段解析规则：

**章节模式**（`#` 开头定义章节）：
```
#日常词汇
apple
banana
#工作词汇
deadline
proposal
```

**默认模式（直接输入）**：
```
apple
banana
carry with
```

> 每行一个单词，支持短语。墨墨会自动识别单词原型。

**接口操作**（完整 URL 前缀为 `https://open.maimemo.com/open`）：

```bash
# 列出已有云词本（分页）
GET /api/v1/notepads?limit=10&offset=0
# 实测返回: {"data":{"notepads":[...]},"success":true}

# 获取单个云词本详情
GET /api/v1/notepads/{notepad_id}

# 创建云词本（content 填单词列表，每行一个）
POST /api/v1/notepads
Content-Type: application/json
{
  "notepad": {
    "title": "有道翻译生词",
    "content": "apple\nbanana\norange\n...",
    "brief": "从有道翻译同步的生词",
    "tags": ["四级"],
    "status": "PUBLISHED"
  }
}
# 实测返回: HTTP 201, {"data":{"notepad":{"id":"np-xxx",...}},"success":true}
# ⚠️ status 必须大写 "PUBLISHED"，小写 "published" 会报 400 错误

# 更新云词本（content 全量替换，⚠️ 不是追加！）
POST /api/v1/notepads/{notepad_id}
Content-Type: application/json
{
  "notepad": {
    "title": "有道翻译生词（更新）",
    "content": "apple\nbanana\n...all-words-including-new"
  }
}

# 删除云词本
DELETE /api/v1/notepads/{notepad_id}
# 实测返回: {"errors":[],"success":true}
```

#### 单词查询 —— vocabulary

```bash
# 查询单个单词（spelling 作为查询参数，不是路径！）
GET /api/v1/vocabulary?spelling=apple
# 实测返回: {"data":{"voc":{"id":"voc-xxx","spelling":"apple"}},"success":true}

# 批量查询（POST 请求，body 传参数）
POST /api/v1/vocabulary/query
Content-Type: application/json
{ "spellings": ["apple", "banana", "orange"] }
# 或按ID查: { "ids": ["voc-xxx", "voc-yyy"] }
# ✅ 2026-08-05 实测返回（⚠️ 字段是 data.voc 单数，值是数组，不是 vocs！）：
# {"errors":[],"data":{"voc":[{"id":"voc-xxx","spelling":"apple"},{"id":"voc-yyy","spelling":"banana"}]},"success":true}
# 未收录的 spelling 不会出现在数组里（需自行比对 missing）。
```

#### 学习计划 —— study（⚠️ 公测，不稳定）

```bash
# 添加单词到学习计划（直接进入复习队列）
POST /api/v1/study/add_words
Content-Type: application/json
{
  "words": [{ "id": "voc-xxxxx" }],
  "advance": false  // false=正常加入, true=提前复习（需账号10级）
}
# 返回: {"data":{"added_count": N},"success":true}

# 查询今日学习进度
POST /api/v1/study/get_study_progress
# 实测返回: {"data":{"progress":{"finished":0,"total":0,"study_time":0}},"success":true}

# 获取今日学习单词
POST /api/v1/study/get_today_items
Content-Type: application/json
{ "is_finished": false, "limit": 20 }

# 查询学习记录
POST /api/v1/study/query_study_records
Content-Type: application/json
{ "spellings": ["apple", "banana"], "limit": 20 }
# ✅ 2026-08-05 实测返回（⚠️ 字段名与前缀猜测全不同，无 familiarity）：
# {"errors":[],"data":{"records":[{"voc_id":"voc-xxx","voc_spelling":"apple",
#   "add_date":"...","first_study_date":"...","last_study_date":"...","next_study_date":"...",
#   "last_response":"STUDY_RESPONSE_UNSPECIFIED","study_count":1,"tags":[]}],"count":0},"success":true}
# 字段映射：voc_spelling→spelling, study_count→reviewCount,
#   last_study_date→lastReviewAt, next_study_date→nextReviewAt, last_response→status。
# 墨墨不返回 familiarity/掌握度，需据 next_study_date 间隔自行推断（间隔越长=掌握越稳固）。
```

## 三、网易有道翻译：获取生词本数据

> 用户使用的是 **有道翻译（fanyi.youdao.com）** 网页版的生词本功能。

有道翻译**没有官方的生词本导出 API**，但有三种获取方式：

### 3.1 方式一：有道翻译网页版导出 CSV（最简单）

```
登录 fanyi.youdao.com → 右上角头像 →「我的生词本」→ 按标签多选 → 导出 CSV
```

**优点**：零技术门槛，稳定可靠
**缺点**：手动操作，无法自动化；需要定期导出

**XML 格式参考**（[qwer10/youdaoXML2word](https://github.com/qwer10/youdaoXML2word)）：
- 标准XML，包含单词、音标、释义等字段
- 可用 Python `xml.etree` 解析

### 3.2 方式二：Web API 抓包（支持自动化）

> 来源：[cx4 抓包分析](https://cx4.github.io/2020/08/27/youdao-dict/)

**查询生词列表**：
```
GET http://youdao.com/wordbook/webapi/words?limit=15&offset=0
Cookie: <你的有道登录Cookie>
```

**响应格式**：
```json
{
  "code": 0,
  "msg": "SUCCESS",
  "data": {
    "total": 4963,
    "itemList": [
      {
        "itemId": "唯一ID",
        "bookId": "生词本ID",
        "bookName": "oxford5000",
        "word": "abandon",
        "trans": "v. 抛弃；放弃",
        "phonetic": "əˈbændən",
        "modifiedTime": 1598351070000
      }
    ]
  }
}
```

**关键参数**：
- `limit`：每页数量，可调大（如 `limit=100`）
- `offset`：分页偏移量
- **必须携带 Cookie**（登录态认证）

**优点**：可编程自动化，数据完整（含翻译、音标）
**缺点**：依赖 Cookie，可能过期需要更新；非官方接口可能变更

### 3.3 方式三：添加生词接口

```
POST http://dict.youdao.com/wordbook/ajax?action=addword&q={word}&date={GMT时间}&le=eng
Cookie: <你的有道登录Cookie>
```

> 主要用于反向操作（往有道添加单词），本方案不需要。

### 3.4 有道数据获取方案对比

| 方式 | 自动化 | 稳定性 | 数据完整度 | 技术难度 |
|------|--------|--------|-----------|---------|
| 网页版导出 CSV | ❌ 手动 | ✅ 高 | ✅ 含音标翻译 | ⭐ |
| Web API 抓包 | ✅ 自动 | ⚠️ Cookie可能过期 | ✅ 含音标翻译 | ⭐⭐⭐ |
| Web API 抓包 + 定时刷新Cookie | ✅ 自动 | ⚠️ 中 | ✅ 含音标翻译 | ⭐⭐⭐⭐ |

> 💡 **建议**：先用网页版导出 CSV 快速验证流程，跑通后再考虑 Web API 自动化。

## 五、推荐实现方案

### 5.1 同步策略对比

| 策略 | API | 优点 | 缺点 | 建议 |
|------|-----|------|------|------|
| **A. 同步到云词本** | `notepads.create/update` | 稳定可靠，单词可浏览管理 | 需在App里手动加入学习计划 | ✅ **首选** |
| **B. 直接加学习计划** | `study.addWords` | 单词直接进复习队列 | 公测接口不稳定；需先查单词ID | 备选 |
| **A+B 组合** | 两个都用 | 云词本做备份 + 学习计划做复习 | 复杂度高 | 进阶方案 |

### 5.2 推荐技术选型

```
语言：Python（生态好，参考项目多）
依赖：
  - requests（HTTP请求）
  - xml.etree.ElementTree（解析有道XML导出）
  - schedule / APScheduler（定时任务，可选）
  - python-dotenv（配置管理）

核心模块：
  ├── youdao_client.py    # 有道生词获取（XML解析 or Web API）
  ├── maimemo_client.py   # 墨墨API调用
  ├── sync_engine.py      # 同步逻辑（去重、增量比对）
  └── config.py           # Token等配置
```

### 5.3 同步逻辑设计

```
首次同步：
  1. 获取有道家词本全部单词
  2. 创建墨墨云词本，content = 全部单词（每行一个）
  3. 记录已同步单词集合

增量同步：
  1. 获取有道家词本新增单词（对比上次同步的记录）
  2. 过滤掉已同步的
  3. 更新墨墨云词本 content（追加新单词）
  4. 更新已同步记录
```

### 5.4 部署方式

| 方式 | 适合场景 | 说明 |
|------|---------|------|
| **手动脚本** | 偶尔同步 | `python sync.py`，最简单 |
| **cron 定时任务** | 定期自动同步 | 每周/每天自动跑 |
| **Docker** | 长期运行 | 参考 eudic-maimomo 的 Dockerfile |
| **GitHub Actions** | 云端免服务器 | cron触发，免费额度够用 |
