## 一、需求概述

### 1.1 背景

用户使用有道翻译（fanyi.youdao.com）查词时将不认识的单词收藏到生词本，希望通过墨墨背单词的间隔重复算法来系统性复习这些生词。

### 1.2 功能需求

| # | 需求 | 优先级 |
|---|------|--------|
| 1 | 导入有道翻译导出的 .bin 文件，解析提取单词 | P0 |
| 2 | 与已有生词去重，只保留新增单词 | P0 |
| 3 | 一键将未同步单词同步到墨墨背单词云词本 | P0 |
| 4 | 在生词本页面展示每个单词的同步状态（待同步/已同步/失败） | P0 |
| 5 | 从墨墨获取单词记忆进度，在生词本页面展示 | P1 |
| 6 | 墨墨 Token 在设置页面配置，前端脱敏不可见 | P0 |

### 1.4 墨墨背单词 API（已实测验证）

| 项目 | 值 |
|------|---|
| Base URL | `https://open.maimemo.com/open` |

```typescript
  tokenMasked: string;

  notepadTitle?: string;

export function maskToken(token: string): string {
  if (!token || token.length <= 8) return token ? '****' : '';
  return `${token.slice(0, 4)}${'*'.repeat(Math.min(token.length - 8, 8))}${token.slice(-4)}`;
}
```

### 3.2 MaimemoClient 设计

```typescript
export class MaimemoClient {
  private readonly baseUrl = 'https://open.maimemo.com/open';

  // Token 通过回调注入（支持热更新，同 GlmWebSearchClient 模式）
  constructor(private readonly getToken: () => string) {}

  // API 方法
  listNotepads(limit?: number, offset?: number): Promise<NotepadListResponse>
```

**关键设计**：
- 使用原生 `fetch`（与项目其他外部调用一致）
- Token 通过 `getToken` 回调注入（不缓存，支持配置热更新）
- 内置简易限速器（滑动窗口：10s/20次）
- 错误处理：401 返回明确提示 Token 无效，429 返回限速提示

### 3.3 MaimemoService 设计

```typescript
export class MaimemoService {
  constructor(
    private readonly configRepository: MaimemoConfigRepository,
```

### 3.4 YoudaoBinParser 设计

```typescript
export interface YoudaoWord {
  word: string;
  phonetic?: string;
  definition?: string;
  groupName?: string;
}

export function parseYoudaoBin(buffer: ArrayBuffer): YoudaoWord[]
```

**解析逻辑**：
1. `new TextDecoder('utf-16le').decode(buffer)` 解码
2. 按 `\0` 分割为段
3. 以 `"en"` 和 `"zh-CHS"` 作为词条分隔标记
4. 每个词条内按顺序提取：单词 → 音标(`[...]`) → 释义（词性开头或中文开头）→ 分组名
5. 防御式解析：缺失字段容错

## 五、核心流程设计

### 5.1 导入流程

```
用户点击"导入有道生词"
  → 选择 .bin 文件
  → FormData 上传到 POST /api/vocab/import-youdao
  → VocabService.importFromYoudaoBin(file)
    → YoudaoBinParser.parse(buffer)  // UTF-16LE 解码
    → 逐个检查 uniqueKey(word|zh) 去重
    → 新单词 syncStatus='pending'，批量 saveAll
  → 返回 VocabImportResult { imported, added, duplicates }
  → toast 提示导入结果
  → 新单词出现在列表中，显示黄色"待同步"徽章
```

### 5.2 同步流程

```
用户点击"同步墨墨"
  → POST /api/maimemo/sync
  → MaimemoService.syncToMaimemo()
    → 检查 Token 是否配置
    → 获取所有 pending 单词
    → 获取所有 synced 单词
    → 合并为完整列表（每行一个单词）
    → 若无 notepadId：
      → maimemoClient.createNotepad(title, content)
      → 保存 notepadId 到 maimemo-config.json
    → 若有 notepadId：
      → maimemoClient.updateNotepad(notepadId, content)  // 全量替换
    → 逐个查询单词 vocId（带限速间隔）
      → 成功：markSynced(maimemoVocId)
      → 失败：markSyncFailed(error)
  → 返回 MaimemoSyncResult { synced, failed, errors }
  → toast 提示同步结果
  → 前端刷新列表，徽章更新
```

**限速策略**：墨墨 API 10s/20次。查询单词 vocId 时，每次请求间隔 ~600ms（20次/12秒，留余量）。

### 5.3 进度查询流程

```
页面加载 / 用户点击"刷新进度"
  → POST /api/maimemo/progress
  → MaimemoService.fetchStudyProgress()
    → 检查 Token
    → 调用 maimemoClient.getStudyProgress()
  → 返回 { finished, total, studyTime }
  → 前端进度条更新
```

> 注意：study API 目前是公测状态，可能不稳定。如果 study 接口不可用，进度条显示为空或降级为"暂不可用"。

## 八、验证方式

1. 启动 dev 环境（shared → backend → frontend）
2. 设置页 → 墨墨 tab → 输入 Token → 测试连接 → 保存
3. 生词本页 → 导入 .bin 文件 → 确认解析和去重正确
4. 点击同步 → 确认墨墨 App 中能看到新单词
5. 刷新进度 → 确认进度数据展示
6. 再次导入同一 .bin 文件 → 确认重复单词被过滤
7. 删除云词本后重新同步 → 确认能正确创建新词本
