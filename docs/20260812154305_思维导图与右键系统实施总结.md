## 三、通用右键菜单系统（全站 8 处）

### 架构（3 层）
```
① 底层 UI     ui/context-menu.tsx        shadcn 封装 radix
② 抽象层     context-menu/types.ts       MenuItem<T,C> 双泛型联合类型
              context-menu/ContextMenuHost 通用包装 + 递归渲染
③ 模块层     各模块 buildXxxItems 工厂    数据驱动，核心零改动
```

**核心设计**：`<ContextMenuHost items={buildXxxItems} target ctx>`，items 是 `MenuItemBuilder<T,C>` 工厂。新视图接入 = 写工厂 + 套 Host，抽象层永不改动。

## 四、关键技术决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 菜单定义风格 | 数据驱动工厂（非 JSX） | 类型安全、动态显隐、跨模块复用 |
| 泛型 | 双泛型 `<T,C>` | target + ctx 都类型安全 |
| 树布局 | 自定义 DFS（替代 dagre） | dagre 不保证同级顺序；DFS 按 children 顺序，排序可控 |
| 撤销 | 手写快照栈（非 zundo） | 轻量，事务粒度，官方示例路线 |
| shared 类型 | 结构同构 interface | 不污染 backend 编译链（不依赖 @xyflow/react） |
| 主题 | OKLCH（非 HSL） | 项目 index.css 已迁 OKLCH，直接 var(--card) |
| 保存 | doSave 核心 + debounce 自动 + Ctrl+S 立即 | 三函数分离，自动/手动共用核心 |
| keep-alive | 画布 key={doc.id} 重挂载 | 文档切换重建受控 state，store 只管文档级 |
