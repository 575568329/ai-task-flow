# uTools 应用市场提交文案(市场版 v0.2.0)

> 用途:在 uTools 开发者工具「插件应用发布」里填写介绍、更新说明、隐私说明时直接取用。
> 截图需自行在 uTools 内按本文末尾清单截取。

## 基本信息

- **名称**:AI 工作记录
- **一句话**:把 AI 在终端干的活,沉淀成可搜索、可回溯、可人工修改的工作记录。
- **分类建议**:效率 / 开发工具
- **关键词**:工作记录、AI、MCP、知识库、思维导图、开发日志

## 详细介绍

AI 工作记录是一个**本地优先、可选账号同步**的工作记录中枢:在终端让 Claude Code / ZCode 干活,
AI 通过 MCP 把改动记成「建设主题 → 版本 → 功能点」,每条记录可以带 diff、文件路径与行号;
你在页面按主题/版本/项目/阶段/关键字回溯,并可直接增删改。

主要功能:

1. **工作记录**:建设主题 → 版本 → 功能点三级结构;条目支持 diff、文件行号、项目归属、阶段标签;全局关键字搜索(标题/详情/文件路径)。
2. **AI 记录(可选)**:在 uTools 设置中开启「AI 设置 → MCP 服务」后,Claude Code / ZCode 等 AI 客户端可调用全部 14 个工具(工作记录 + 结论卡 + 知识库)。也可继续用本地 stdio MCP。
3. **结论卡**:长对话结论按主题沉淀,结论/数据/待办/代码位置逐版可查。
4. **知识库**:Markdown 文档库,目录树 + 多视图 + 全文写入。
5. **思维导图**:画布编辑,Mermaid 导入。

数据默认保存在本机 `~/.ai-task-flow`,支持与本地桌面版/命令行 MCP 共用同一份数据。
开启 uTools「数据同步」后,工作记录/结论卡/思维导图/知识库文本会通过 uTools 账号同步到其他设备;
插件自身不上传数据、不做统计上报。LLM 配置、Claude 配置和上传图片不同步。

## 隐私说明

- 不收集账号、设备标识或使用统计,无遥测。
- 不监听/轮询剪贴板;只有用户点击「复制」时写入剪贴板。
- 工作记录、结论卡、知识库、思维导图、上传图片、LLM 配置、Claude 配置快照默认保存在本机 `~/.ai-task-flow`。
- 用户开启 uTools「数据同步」后,工作记录/结论卡/思维导图/知识库文本通过 uTools 账号同步;同步由 uTools 客户端处理,插件自身不上传。
- LLM 配置、Claude 配置(含密钥)与上传图片**不同步**,只保存在当前设备。
- LLM 配置中的 API Key 只存本机;仅当用户主动测试/使用 AI 功能时,请求发往用户填写的 API 地址。
- 工作记录 MCP 只连接本机 `127.0.0.1`,不与外部服务器通信。
- 卸载插件不会自动删除数据目录,用户可自行清理。

## 版本说明 v0.2.0

- 首个市场版本:工作记录(主题→版本→条目)、结论卡、知识库、思维导图。
- 市场版不提供「Claude 配置切换」(会读写用户其他工具的配置),个人版/桌面版保留。
- 支持 uTools 内置 MCP:全部 14 个工具(工作记录 11 + 结论卡 2 + 知识库 1)。
- 数据与本地桌面版/MCP 共用 `~/.ai-task-flow`,无需导入。
- 适配 uTools 8(Chromium 132),支持 802 主窗与深浅色。

## 审核自查口径(提交前)

- 包内无 `.exe/.dll/.so/.dylib/.node` 原生二进制;无 `.map`、`.git`、测试目录、开发机路径。
- `preload.js` 及 `preload-tools.js` 为明文可读;仅暴露固定的本机 `backendBase` 与 `ready`,不向页面暴露 fs/子进程/任意 URL。
- preload 内部使用 `child_process` 拉起自带的 `backend/plugin-entry.mjs`,运行环境是 uTools 自带的 Electron Node
  (`process.execPath` + `ELECTRON_RUN_AS_NODE=1`),不依赖用户安装 Node,也不下载/执行外部程序。
- 无远程代码加载、无外部 `<script>`、无剪贴板轮询、无硬编码密钥。
- `utools.db` 仅写业务数据快照(gzip 分片:工作记录/结论/思维导图/知识库文本),不写日志、缓存、密钥或图片,符合同步数据库的用途要求。
- logo 为原创图,非 uTools 默认占位图。
- 详细检查脚本:`node tools/utools/check-plugin.mjs`。
